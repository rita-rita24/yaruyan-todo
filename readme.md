# やるやん！Todo

**やることを整理して、集中して、気持ちよく完了するためのローカルTodoツールです。**

`yaruyan-todo.html` をブラウザで開くだけで使えます。サーバーやアカウント登録は不要です。タスクを親子で分け、開始ボタンから集中モードに入り、完了した作業には実績時間を残せます。

業務UI版に統一しています。完了状態のフィルタとドラッグ時の差し込み表示を備え、CSS・JavaScriptを内包するHTML単体で動作します。

CSSのネスト、`light-dark()`、`structuredClone()`、Canvasの`roundRect()`に対応するモダンブラウザを対象としています。

## どんなツール？

やることが増えると、タスク管理は「書く場所」と「実際に手を付ける場所」が分かれがちです。やるやん！Todoは、その間を短くするための1ファイル完結Todoです。

- 今日やることを親タスク / 子タスクで整理できます
- 作業を始めるときは集中モードに切り替えられます
- 完了時には実績時間と達成感のある演出が残ります
- 思いついたことは整理メモに逃がせます
- データは端末内のブラウザ保存に残ります

## こんなときに便利

- 個人作業のTodoを軽く、でも見やすく管理したい
- 案件や作業を親子タスクに分けて進めたい
- 「開始」と「完了」をはっきりさせて作業時間を残したい
- ネットワークやログインなしで使える道具がほしい
- メモ、タスク、集中タイマーをひとつの画面で回したい

## すぐ使う

1. `yaruyan-todo.html` をブラウザで開きます
2. `タスクを追加` に今日やることを入力します
3. 追加したタスクの `開始` を押して集中モードに入ります
4. 作業が終わったら `完了` を押します
5. 必要に応じて子タスク、整理メモ、テーマ設定を使います

## 主な機能

- 親タスク / 子タスクの作成、編集、削除、並び替え
- `すべて / 未完了 / 完了` の表示フィルタ
- 全体の完了件数と進捗表示（子タスクのある親は二重計上しません）
- 集中モードの開始、一時停止、再開、完了、中断
- 集中モード中は中央のコンパクトな表示で経過時間を確認し、背面を見ながらスクロールできます
- 実績時間の表示
- ポモドーロ設定（集中時間 / 休憩時間）
- 整理メモのローカル保存
- ライト / ダークモードとテーマカラー変更
- 完了メッセージ、効果音、お祝い表示の設定
- 削除後のUndo復元
- 入力中の誤発火を抑えたキーボード操作とモーダルのフォーカス管理
- 自動保存や集中タイマーの操作後も、入力欄やボタンの選択位置を維持
- 集中操作の文字ラベル
- JSONバックアップの書き出し / 読み込み

完了フィルタから追加した場合は、追加したタスクが見えるよう「すべて」に切り替わります。

## 開発・品質確認

Node.js 22を使用します。追加パッケージのインストールやビルドは不要です。

```sh
npm test
```

`npm test` は配布HTMLの構文、保存・復元・入力・集中タイマー、フィルタ・ドラッグ操作を検証します。テストは `tests/helpers/app-source.mjs` を通して業務UI版の実コードを読み込みます。

実ブラウザの確認用コピーは、例えば `node tests/create-continuity-qa.mjs` や `node tests/create-storage-commit-qa.mjs` で生成できます。表示された一時ディレクトリをlocalhostで配信して `index.html` を開いてください。保存キーとDB名は通常利用のデータから分離されます。

直近の実画面確認と、販売前に残る確認範囲は `quality.md` に記録しています。

### HTML・CSS・JavaScriptの編集方針

- 配布HTMLを直接編集します。外部ファイルの読み込みやビルド工程は不要です。
- CSSは `reset / base / component / utility / theme` のレイヤー順を明示し、アプリ固有の共通変数は `base` にまとめています。状態・疑似要素・子要素はCSS標準のネストで記述し、セレクターの詳細度と適用順を保ちます。
- コンポーネント単位の画面幅による切り替えは、そのルール内に `@media` をネストします。複数コンポーネントにまたがるルールは共通のメディアクエリーに残し、広い幅から狭い幅の順で上書きします。トランジションは変化するプロパティを明示します。
- 基本文字サイズは14px相当とし、ブラウザ100%で元の大きさになります。幅・余白・アイコンは `rem`、画面幅による切り替えは `em` で管理します。
- 固定の見た目はCSS、表示状態は `hidden`、配色は `data-mode` で管理します。座標やテーマの色見本など、実行時に決まる値だけをJSからスタイルへ設定します。
- ツールチップの文言はボタンの `aria-label` を共用します。`title` や専用の文言属性は追加せず、アイコンだけのボタンに独自ツールチップを表示します。Escapeキーで閉じられます。
- SVGアイコンの利用可能な名前はHTML内のスプライトから取得します。アイコンを追加するときにJSへ同じ一覧を重複定義する必要はありません。
- 入力欄のEnter操作は `bindInputEnter()` で日本語変換とキーリピートの扱いを共通化します。タスク・メッセージの一覧更新は `reconcileChildren()` で変更のないDOMを維持し、編集位置やフォーカスを保ちます。
- サイドバーの表示切り替えは `MediaQueryList` の `change` イベントで境界をまたいだときだけ更新します。
- 変更後は `npm test` と必要なブラウザ検証で確認します。

## 保存について

タスク、整理メモ、設定はブラウザ内に保存されます。通信先サーバーは使わず、端末内で完結します。

保存内容は `localStorage` と `IndexedDB` の世代情報を比較して復元します。IndexedDB対応環境では、競合確認と書き込みを同じトランザクション内で行い、確定してからlocalStorageへ反映します。未対応環境ではlocalStorageへ保存します。読み込み中は編集を制限し、ページ離脱時の一時保存は次回起動時に確定済みのデータと照合します。

保存済みタスクに破損した項目や安全でないIDが含まれている場合は、起動時に使える項目だけを読み込み、IDを安全な形式に修復します。

集中モード中は実績時間を定期的に保存します。別タブで新しい保存内容が見つかった場合は、古いタブからの上書きを止め、再読み込みを促します。

メモは入力中・入力欄を離れたときにも保存します。日本語変換やクリック・ドラッグを妨げないよう、自動保存の操作ロックを待機させます。保存失敗時は直前の状態を復元し、集中計測やポモドーロ設定も同期します。

設定画面のバックアップから、タスク、設定、整理メモ、表示フィルタをJSONで書き出し / 読み込みできます。読み込み時は、このアプリのバックアップ形式かを検証し、タスクIDや設定値を安全な形式へ正規化します。

ブラウザデータを削除すると端末内の保存内容は消えます。定期的にバックアップJSONを書き出して保管してください。
