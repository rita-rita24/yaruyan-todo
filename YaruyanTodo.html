    タスク、設定、整理メモ、表示フィルタをJSONで保存/復元します。読み込みは上限サイズまでです。

    端末やブラウザを変えるときは、ここで書き出したファイルを移動先で読み込んでください。ブラウザのデータを消す前にもバックアップを保管してください。

    使い方とキーボード操作

    タスクを追加し、「開始」で時間を計測。「一時停止」は席を離れるときに使います。「中断」は計測時間を破棄し、未完了のまま一覧へ戻ります。

    大きな作業は「編集」から子タスクに分けられます。子タスクのある親は、すべての子タスクを終えると完了になります。

    Alt + N
    タスクの入力へ
    Alt + 1 / 2 / 3
    タスク / 整理メモ / 設定へ
    Alt + ↑ / ↓
    選択中のタスクを並び替え
    Esc
    編集・確認画面を閉じる

    タスク名は120文字、親タスクは200件、子タスクは親ごとに50件まで追加できます。
